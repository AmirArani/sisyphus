# sisyphus

> One boulder, one hill, one family. Updated daily, blocked daily.

A small, hand-picked list of working connections for the family. Every day one of them stops working, and every day it gets replaced. The boulder rolls back down, and we push it up again.

## How to use it

1. Copy the subscription link: `https://raw.githubusercontent.com/AmirArani/sisyphus/refs/heads/main/sisyphus.txt`
2. Open your app and add a new subscription with that link.
3. Update the subscription, then pick a connection from the list.

If something stops working, **update the subscription first**. That fixes it most of the time.

## Still not working?

Try another connection from the list. If none of them work, message Amir.

## Notes

- The list changes often. Old connections disappear and new ones appear. That's normal.
